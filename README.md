# React Product Store

A React 19 + Vite storefront UI styled with Tailwind CSS v4.

## Requirements
- Node.js 20.19+ or 22.12+
- npm

## Setup
```bash
npm install
npm run dev
```

## Validation
```bash
npm run lint
npm run build
```

The `node_modules` directory is intentionally not included in this archive. Install dependencies on your own machine so npm can download the correct native packages for your operating system.
